# 体重ダッシュボード 設定手順

体重計に乗ってオムロン コネクトを開いて閉じるだけで、体重がGoogleスプレッドシートに記録され、iPhoneに要約が通知され、ホーム画面のアイコンから計器盤ページを見られるようにする手順です。

- 用意するもの：iPhone（iOS 17以降）、パソコン、Googleアカウント、オムロン コネクトと連携した体重計
- かかる時間：1時間くらい
- この手順書の数値（体重・目標・日付）はすべて架空の例です。自分の値に置き換えてください。
- **合言葉・スプレッドシートのID・ページのURLは、他の人に教えないでください。** このリポジトリにも書かないでください（公開されています）。

仕組みの全体像：

```
体重計 → オムロン コネクト → iPhoneのヘルスケア
  → ショートカット（オムロン コネクトを閉じたとき自動で動く）
      → ① 受け取り口（Apps Script「ingest」）→ スプレッドシート「体重ログ」に保存 → 要約1行を通知
      → ② 計器盤ページ（Apps Script「dashboard」）→ シートを読んで表示
```

手順の順番：

1. [スプレッドシートを作る](#1-スプレッドシートを作る)
2. [受け取り口のApps Scriptを作る](#2-受け取り口のapps-scriptを作る)
3. [計器盤ページのApps Scriptを作る](#3-計器盤ページのapps-scriptを作る)
4. [オムロン コネクトのヘルスケア連携](#4-オムロン-コネクトのヘルスケア連携)
5. [ショートカットを作る](#5-ショートカットを作る)
6. [オートメーションを作る](#6-オートメーションを作る)
7. [ホーム画面に追加する](#7-ホーム画面に追加する)
8. [うまくいかないとき](#8-うまくいかないとき)

## 1. スプレッドシートを作る

パソコンで行います。

1. [sheets.google.com](https://sheets.google.com) を開き、「空白のスプレッドシート」を作ります。
2. 左上の「無題のスプレッドシート」をクリックして、名前を「体重」など好きな名前に変えます。
3. 下のシート見出し「シート1」をダブルクリックして、名前を **`体重ログ`** に変えます。
4. 「体重ログ」の1行目に、次の4つの見出しを左から順に入れます。

   | A | B | C | D |
   |---|---|---|---|
   | 日付 | 体重kg | 測定時刻 | 受信日時 |

   2行目から下は空のままにします（ショートカットが自動で書き込みます）。
5. 左下の「＋」で新しいシートを追加し、名前を **`設定`** に変えます。
6. 「設定」に、次のように書きます（値は架空の例です。自分の目標に置き換えてください）。

   | | A | B | C |
   |---|---|---|---|
   | 1 | 目標日 | 2026-12-05 | |
   | 2 | 目標体重 | 70.0 | |
   | 3 | 開始日 | 2026-10-11 | |
   | 4 | チェックポイント | 2026-11-01 | 72.0 |

   - **目標日**：この日に目標体重に着地する、という日付。
   - **目標体重**：着地する体重（kg）。
   - **開始日**：グラフの左端。進捗の起点になります。
   - **チェックポイント**：「この日にこの体重まで落とす」という途中の目標。B列に日付、C列に体重。いらなければ行ごと消してかまいません。何行でも書けます。目標日より前の日付にしてください。
   - 日付は `2026-12-05` のように「年-月-日」で書きます。入力後にGoogleが日付の表示を変えても（例：2026/12/05）そのままで大丈夫です。
7. **シート名と見出しは、上の文字とまったく同じ**にしてください（全角・半角、空白の有無も含めて）。違うと「シートが見つかりません」というエラーになります。
8. ブラウザのアドレス欄にあるURLをメモしておきます。URLは次の形です。

   ```
   https://docs.google.com/spreadsheets/d/ここがスプレッドシートのID/edit#gid=0
   ```

   `/d/` と `/edit` のあいだの長い文字列が **スプレッドシートのID** です。あとで2回使います。

「設定」シートはiPhoneのGoogleスプレッドシートアプリからも直せます。目標を変えたいときは、ここを書き換えるだけでページと通知に反映されます。

## 2. 受け取り口のApps Scriptを作る

iPhoneから送られてきた体重を受け取って、「体重ログ」に書き込むプログラムです。

### 2.1 プロジェクトを作ってファイルを貼る

1. [script.google.com](https://script.google.com) を開き、「新しいプロジェクト」をクリックします。
2. 左上の「無題のプロジェクト」をクリックして、名前を **`体重 ingest`** などに変えます。
3. 左の「ファイル」欄に `コード.gs` があります。これを使って、このリポジトリの **`gas/ingest/Code.js`** の中身をすべて貼り付けます。
   - エディタの中身を全部選んで削除してから、貼り付けます。
   - `コード.gs` の名前は、横の「︙」→「名前を変更」で **`Code`** に変えます（`.gs` は自動で付きます）。
4. 「ファイル」欄の「＋」→「スクリプト」をクリックし、名前を **`Metrics`** にします。ここに **`gas/shared/Metrics.js`** の中身をすべて貼り付けます。
5. マニフェストを表示します。左の歯車「プロジェクトの設定」→「**「appsscript.json」マニフェスト ファイルをエディタで表示する**」にチェックを入れます。
6. 「ファイル」欄に `appsscript.json` が出ます。これを開き、中身を **`gas/ingest/appsscript.json`** の内容で全部置き換えます。
7. 「保存」（フロッピーのアイコン、または Ctrl+S / ⌘S）を押します。

このプロジェクトに入れるファイルは、次の3つだけです。

| リポジトリのファイル | エディタでの名前 | 種類 |
|---|---|---|
| `gas/shared/Metrics.js` | `Metrics` | スクリプト |
| `gas/ingest/Code.js` | `Code` | スクリプト |
| `gas/ingest/appsscript.json` | `appsscript.json` | マニフェスト |

**`gas/test/` の中のファイルは貼らないでください。** 自動テスト用で、Apps Scriptでは動きません。

### 2.2 スクリプトプロパティを設定する

スプレッドシートのIDと合言葉を、コードの外に保存します。

1. まず合言葉を作ります。「ファイル」欄の「＋」→「スクリプト」で一時的なファイル（名前は `tmp` など）を作り、次の2行を貼ります。

   ```js
   function makeToken() { console.log(Utilities.getUuid() + Utilities.getUuid()); }
   ```

2. 保存して、上の関数名の欄で `makeToken` を選び、「実行」を押します。
3. 下に「実行ログ」が開き、英数字とハイフンの長い文字列（70文字ほど）が出ます。これが**合言葉**です。コピーしてメモ帳などに控えます。iPhoneのショートカットにも入れるので、iPhoneから見られる場所（メモアプリなど）に控えると楽です。
   - 合言葉を知っている人は、あなたのシートに体重を書き込めます。**人に教えたり、どこかに公開したりしないでください。**
4. 控えたら、一時ファイル `tmp` は「︙」→「削除」で消します。
5. 左の歯車「プロジェクトの設定」を開き、いちばん下の「スクリプト プロパティ」で「スクリプト プロパティを追加」を押します。次の2つを登録します。

   | プロパティ | 値 |
   |---|---|
   | `SHEET_ID` | 手順1でメモしたスプレッドシートのID |
   | `INGEST_TOKEN` | 手順3で作った合言葉 |

6. 「スクリプト プロパティを保存」を押します。
   - 前後に空白が入らないように注意してください。

### 2.3 動作を確かめる（`testIngest`）

本番と同じ処理を、シートに書き込まずに試します。

1. 「体重ログ」はまだ空なので、試すための行を1行だけ手で入れます。「体重ログ」の2行目に、**今日の日付**と架空の体重を書きます（受信日時は空でかまいません）。

   | A | B | C | D |
   |---|---|---|---|
   | 2026-11-05 | 71.6 | 07:12 | |

2. Apps Scriptのエディタに戻り、「Code.gs」を開いて、関数名の欄で **`testIngest`** を選び、「実行」を押します。
3. 初回は「承認が必要です」と出ます。「権限を確認」→ 自分のGoogleアカウントを選びます。
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動（安全ではないページ）」を押します。自分で作ったプログラムなので問題ありません。
   - 「許可」を押します。
4. 実行ログに、次のような2行が出れば成功です（数値は例）。

   ```
   samples: 2026-11-05T07:12,71.6
   71.6kg
   ```

   1行目は試しに送った測定、2行目はiPhoneに届く通知の文面です。データが1日分しかないので、この時点では体重だけです。4日以上たまると `71.6kg ▲0.3｜目標ライン −0.1 順調｜予測 69.8（T−30）` のように、目標ラインとの差や予測が付きます（数値は例）。
   - `testIngest` はシートの最後の行をそのまま送り直すので、シートは変わらず、実行ログもこの2行だけです。3行目は出ません。
   - 代わりに `ERROR: …` が出たときは、[8. うまくいかないとき](#8-うまくいかないとき)の表を見てください。
   - 「体重ログに行がないので、試す測定がありません」と出たときは、手順1の行が入っていません。
5. **確かめ終わったら、手順1で入れた試しの行を必ず消してください**（行を選んで右クリック →「行を削除」。見出し行は残します）。ショートカットを作る前に消します。
   - 受け取り口は、同じ日の記録があるとき、**より早い時刻**の測定でしか置き換えません。試しの行より遅い時刻に本当の測定をすると、架空の体重がその日の値として残り、7日平均や予測にも使われてしまいます。

### 2.4 ウェブアプリとして公開する（デプロイ）

1. 右上の「デプロイ」→「新しいデプロイ」を押します。
2. 左の歯車「種類の選択」→「**ウェブアプリ**」を選びます。
3. 次のように設定します。
   - 説明：空でも、「受け取り口」などでも可
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
     （iPhoneのショートカットはGoogleにログインできないため「全員」にします。合言葉がないと何も書き込めないので、URLと合言葉が漏れなければ安全です）
4. 「デプロイ」を押します。初回は「アクセスを承認」が出るので、2.3と同じ手順で許可します。
5. 「ウェブアプリ」の **URL**（`https://script.google.com/macros/s/…/exec` のように `/exec` で終わるもの）をコピーして控えます。これを**受け取り口のURL**と呼びます。あとでiPhoneのショートカットに入れます。
6. 「完了」を押します。

> **あとでコードを更新したとき**：「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→ バージョンを「**新バージョン**」にして「デプロイ」。こうするとURLが変わらず、ショートカットを直さずに済みます。「新しいデプロイ」を作るとURLが変わるので注意してください。

## 3. 計器盤ページのApps Scriptを作る

ページを表示するプログラムです。受け取り口とは**別のプロジェクト**にします（同じプロジェクトに置くと、受け取り口のURLから体重が見えてしまうためです）。

### 3.1 プロジェクトを作ってファイルを貼る

1. [script.google.com](https://script.google.com) で、もう一度「新しいプロジェクト」を作ります。名前は **`体重 dashboard`** などにします。
2. 手順2.1と同じ要領で、次の4つのファイルを入れます。

   | リポジトリのファイル | エディタでの名前 | 種類（「＋」で選ぶもの） |
   |---|---|---|
   | `gas/shared/Metrics.js` | `Metrics` | スクリプト |
   | `gas/dashboard/Code.js` | `Code` | スクリプト（最初からある `コード.gs` を名前変更して使う） |
   | `gas/dashboard/Page.html` | `Page` | **HTML** |
   | `gas/dashboard/appsscript.json` | `appsscript.json` | マニフェスト（「プロジェクトの設定」で表示してから置き換える） |

   - `Page` は「＋」→「**HTML**」で作ります。「スクリプト」で作ると動きません。
   - `Metrics` には、受け取り口と**同じ** `gas/shared/Metrics.js` を貼ります。
   - **`gas/test/` の中のファイルは貼らないでください。**
3. 保存します。

### 3.2 スクリプトプロパティを設定する

「プロジェクトの設定」→「スクリプト プロパティ」で、次の1つだけ登録します。

| プロパティ | 値 |
|---|---|
| `SHEET_ID` | 手順1でメモしたスプレッドシートのID（受け取り口と同じ値） |

合言葉（`INGEST_TOKEN`）はこちらには入れません。

### 3.3 ウェブアプリとして公開する（デプロイ）

1. 「デプロイ」→「新しいデプロイ」→ 種類「**ウェブアプリ**」。
2. 次のように設定します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**（体重は自分だけが見られるようにします）
3. 「デプロイ」を押し、初回は2.3と同じ手順で許可します。
4. `/exec` で終わる **URL** を控えます。これを**ページのURL**と呼びます。
5. パソコンのブラウザでページのURLを開いてみます。
   - 体重ログが空なので「まだ記録がありません。オムロン コネクトで測ってアプリを閉じると、ここに表示されます。」と表示されます。これで正常です（2.3の試しの行は消してあるはずです。まだ残っていれば、その値で計器盤が表示されるので、ここで消してください）。
   - 「表示できませんでした」と出たら、その下の文章に足りないものが書いてあります。[8. うまくいかないとき](#8-うまくいかないとき)も見てください。

コードを更新したときの反映のしかたは、2.4の「あとでコードを更新したとき」と同じです。

## 4. オムロン コネクトのヘルスケア連携

ここからはiPhoneで行います。体重計の測定値が、オムロン コネクトからiPhoneの「ヘルスケア」アプリに自動で入るようにします。

1. オムロン コネクトを開きます。
2. 「コンテンツ」→「コンテンツ追加」→「ヘルスケア」→「連携設定」の順に進みます（アプリの版によって、設定画面の中にある場合もあります）。
3. 「体重」の連携をオンにします。iPhoneの「ヘルスケア」の許可画面が出たら、「体重」の書き込みを許可します。
4. 確認：体重計で一度測り、オムロン コネクトに値が出たら、iPhoneの「ヘルスケア」アプリ →「ブラウズ」→「身体測定値」→「体重」を開きます。同じ値が入っていれば成功です。

## 5. ショートカットを作る

ヘルスケアから直近14日分の体重を読み、受け取り口に送って、返ってきた要約を通知に出すショートカットです。

用意しておくもの：**受け取り口のURL**（2.4）と**合言葉**（2.2）。iPhoneで貼り付けられるように、メモアプリなどに入れておきます。

> アクションや項目の名前は、iOSの版によって少し違うことがあります。似た名前のものを探してください。アクションは、画面下の検索欄に名前を入れると見つかります。

1. 「ショートカット」アプリを開き、右上の「＋」で新しいショートカットを作ります。名前は「体重を送る」などにします。
2. 次のアクションを、上から順に追加します。

   **(1) 待機**
   - 「待機」を追加し、秒数を **5** にします。
   - オムロン コネクトがヘルスケアに書き込み終わるのを待つためです。

   **(2) ヘルスケアサンプルを検索**
   - 「ヘルスケアサンプルを検索」を追加します。
   - 種類：**体重**
   - 「フィルタを追加」→ **開始日** が **過去14日以内**（「〜以内」「最近の〜」などの表現で、14日を指定）
   - 並べ替え：**開始日**、順序：**最新順**（新しい順）
   - 上限：**オフ**（すべて）
   - 初めて実行するときに、ヘルスケアの読み取り許可を聞かれます。「体重」を許可します。

   **(3) 各項目を繰り返す**
   - 「各項目を繰り返す」（「繰り返す（各項目）」と表示されることもあります）を追加します。繰り返す対象は、(2)の「ヘルスケアサンプル」になっているか確かめます。
   - 繰り返しの中に、次の3つを入れます。

     **(3a) 日付をフォーマット**
     - 「日付をフォーマット」を追加します。
     - 日付：「繰り返し項目」をタップして選び、さらにその中の **開始日** を選びます。
     - 日付の書式：**カスタム**
     - 書式の文字列：`yyyy-MM-dd'T'HH:mm` （そのまま、半角で入力。`'T'` の前後は半角のシングルクォート）
     - 例：`2026-11-05T07:12` のような文字になります。

     **(3b) テキスト**
     - 「テキスト」を追加し、本文を次の1行にします（カンマは半角）。

       ```
       （フォーマット済みの日付）,（繰り返し項目の値）
       ```

       - 「（フォーマット済みの日付）」の部分には、(3a)の結果「フォーマット済みの日付」を変数として入れます。
       - 「（繰り返し項目の値）」の部分には、「繰り返し項目」→ **値** を入れます。入れた変数をタップすると**単位**を選べるので、**kg** にします。
       - 単位の選択肢が出ない場合は、(3a)の前に「計測値を変換」を入れて、繰り返し項目をキログラム（kg）に変換し、その結果を使ってください。
       - 値が `71.6 kg` のように単位つきの文字になる場合は、受け取り口が読めません。「計測値を変換」の後ろに「**入力から数字を取得**」を入れて数字だけにし、その結果を使ってください。
     - できあがりの1行の例：`2026-11-05T07:12,71.6`（カンマの後ろは数字だけ。`kg` の文字は付けません）

     **(3c)** 繰り返しの最後は、この「テキスト」の結果がそのまま次へ渡ります。何も足さなくてかまいません。

   **(4) テキストを結合**
   - 繰り返しの外（「繰り返しの終了」の下）に「テキストを結合」を追加します。
   - 結合するもの：**繰り返しの結果**
   - 区切り：**改行**

   **(5) URLの内容を取得**
   - 「URLの内容を取得」を追加します。
   - URL：**受け取り口のURL**（2.4で控えた `/exec` で終わるもの）
   - 「詳細を表示」を開きます。
   - 方法：**POST**
   - 本文を要求：**フォーム**
   - 「新規フィールドを追加」→「テキスト」で、次の2つを作ります。

     | キー | 値 |
     |---|---|
     | `token` | 合言葉（2.2で作った文字列をそのまま貼る） |
     | `samples` | (4)の「結合したテキスト」の変数 |

   - キーは半角小文字です。

   **(6) 通知を表示**
   - 「通知を表示」を追加します。
   - 内容：(5)の「URLの内容」の変数
   - 「実行時に表示」はオンのままで大丈夫です。

3. 右上の「完了」で保存します。
4. **試してみる**：ショートカットの一覧で、作ったショートカットをタップして実行します。
   - 数秒後に、`71.6kg ▲0.3｜目標ライン −0.1 順調｜予測 69.8（T−30）` のような通知が出れば成功です（数値は例。日数が少ないうちは「目標ライン」や「予測」が出ません）。
   - スプレッドシートの「体重ログ」を開くと、ヘルスケアにある日ごとに行が増えています。
   - `ERROR: …` と出たとき、通知が出ないときは、[8. うまくいかないとき](#8-うまくいかないとき)を見てください。

補足：

- 毎回14日分を送るのは、1回失敗しても次に成功したときに抜けた日が埋まるようにするためです。同じ日に2回以上測っても、その日の**いちばん早い時刻**の値だけが記録されます（朝の体重を使う前提です）。
- iPhoneの時刻設定は日本時間にしておいてください。別の時間帯だと日付がずれます。

## 6. オートメーションを作る

オムロン コネクトを閉じたときに、手順5のショートカットが自動で動くようにします。

1. 「ショートカット」アプリの下の「オートメーション」タブを開き、右上の「＋」（または「新規オートメーション」）を押します。
2. 一覧から「**App**」を選びます。
3. 「選択」でアプリを選びます。**オムロン コネクト**を選び、「完了」。
4. 「**閉じたとき**」にチェックを入れます（「開いたとき」のチェックは外します）。
5. 「**すぐに実行**」を選びます（iOS 17以降。これを選ぶと、毎回「実行しますか？」と聞かれずに動きます）。「実行時に通知」はオフにしてかまいません。
6. 「次へ」を押し、手順5で作ったショートカット（「体重を送る」）を選びます。
7. 確認：体重計で測り、オムロン コネクトを開いて値が入ったのを見てから、アプリを閉じます（ホーム画面に戻るか、別のアプリに切り替える）。数秒後に通知が出れば成功です。

**なぜ「閉じたとき」なのか**：iPhoneは、画面がロックされているあいだはヘルスケアのデータを読めません。「毎朝7時に」のような時刻の指定だと、そのときiPhoneがロックされていて失敗します。アプリを閉じた瞬間なら、必ずロックが解除されているので確実に動きます。

## 7. ホーム画面に追加する

計器盤ページを、iPhoneのホーム画面からアプリのように開けるようにします。

1. iPhoneの **Safari** で、**ページのURL**（3.3で控えた `/exec` で終わるもの）を開きます。
   - Googleのログイン画面が出たら、**Apps Scriptを作ったのと同じGoogleアカウント**でログインします。別のアカウントだと「アクセス権がありません」と表示されます。
   - 計器盤が表示されることを確かめます（記録がなければ「まだ記録がありません…」の表示）。
2. 画面下の共有ボタン（□に↑）をタップします。
3. 「**ホーム画面に追加**」をタップします。
4. 名前を「体重」などにして「追加」。
5. ホーム画面のアイコンから開いて、ページが表示されることを確かめます。

- アイコンはApps Scriptの標準のものになります（変えられるかは未確認です）。
- 開くたびにログインを求められる場合は、Safariで一度ログインしたままにしておくと、以後は求められないことが多いです。Safariの「プライベートブラウズ」では毎回求められます。
- ページは開くたびにシートを読んで計算します。表示に数秒かかることがあります。

これで設定は終わりです。毎朝、体重計に乗ってオムロン コネクトを開いて閉じるだけで、通知とページが更新されます。

## 8. うまくいかないとき

### 通知や実行ログに `ERROR:` が出る

受け取り口が返すエラーと、その意味です。

| 表示 | 意味 | 直し方 |
|---|---|---|
| `ERROR: 合言葉が違います` | ショートカットの `token` と、受け取り口の `INGEST_TOKEN` が一致しない | 両方を見比べて、同じ文字列にする。前後の空白や改行が入っていないか確かめる |
| `ERROR: 合言葉が設定されていません` | 受け取り口のプロジェクトにスクリプトプロパティ `INGEST_TOKEN` がない | 2.2の手順5で登録する。名前は半角大文字で `INGEST_TOKEN` |
| `ERROR: 有効な測定がありません` | 送られた行が1行も読めなかった | 下の「有効な測定がありません、の原因」を見る |
| `ERROR: スクリプトプロパティ SHEET_ID がありません` | スクリプトプロパティ `SHEET_ID` がない | 2.2（または3.2）の手順で登録する |
| `ERROR: シート「体重ログ」が見つかりません`<br>`ERROR: シート「設定」が見つかりません` | シート名が違う | シート名を `体重ログ` / `設定` にする（全角・半角、空白に注意） |
| `ERROR: 設定シートに目標日がありません`<br>`…目標体重がありません`<br>`…開始日がありません` | 「設定」シートにその行がない、またはB列が空 | 1の手順6のとおりに書く。A列の項目名は `目標日`・`目標体重`・`開始日`・`チェックポイント` |
| `ERROR: 設定シートの目標日の形式が違います（N行目）`<br>（目標体重・開始日・チェックポイントも同様） | その行の値が日付や数値として読めない | 日付は `2026-12-05` の形、体重は `70.0` のような数値にする |
| `ERROR: チェックポイントは目標日より前の日付にしてください（N行目）` | チェックポイントの日付が目標日と同じか、あと | その行の日付を目標日より前にするか、行を消す |
| `ERROR: 体重ログの形式が違います（N行目）` | 「体重ログ」のその行の日付か体重が読めない | その行を直すか消す。手で書くときは日付 `2026-11-05`、体重は数値 |
| `ERROR: `（そのほか） | 予期しないエラー | Apps Scriptの「実行数」（左の時計のアイコン）でエラーの内容を見る |

「表示できませんでした」のときにページに出る文章も、上の表の `ERROR: ` を除いた部分と同じです。

**有効な測定がありません、の原因**

受け取り口は、次に当てはまる行を捨てます。全部捨てられるとこのエラーになります。

- 行の形が `2026-11-05T07:12,71.6` と違う。「日付をフォーマット」の書式が `yyyy-MM-dd'T'HH:mm` になっているか、カンマが半角か、体重が `71.6 kg` のように単位つきになっていないか（手順5の(3b)）、を確かめる。確かめるには、ショートカットの「テキストを結合」の直後に「クイックルック」を一時的に足して、送る文字を見ると早いです。
- 体重が30〜200kgの範囲外。
- 日時が未来（1時間より先）か、60日より前。iPhoneの時刻設定を確かめる。
- そもそも送った行が0行。ヘルスケアに体重が入っていない（手順4）、またはショートカットにヘルスケアの読み取りが許可されていない（iPhoneの「設定」→「ヘルスケア」→「データアクセスとデバイス」→「ショートカット」で「体重」を許可）。

### 通知が出ない、または通知の中身が空・意味のない文字

- 受け取り口は、送られたデータを書き込んだあと、返事を別のURLへの転送（リダイレクト）で返します。ショートカットがこの転送をたどれないと、通知が空になったり、HTMLのような文字が出たりします。この場合でも**スプレッドシートへの記録はできています**。「体重ログ」を見て、行が増えていれば受け取りは成功しています。
- 通知の文面がほしいときは、送り方を**GET**に変えて試してください。「URLの内容を取得」を次のように直します。
  1. 「結合したテキスト」の後ろに「**URLエンコード**」のアクションを足し、結合したテキストをエンコードします。
  2. 方法：**GET**（本文の設定は消えます）
  3. URL：`受け取り口のURL?token=合言葉&samples=（URLエンコードしたテキスト）` の形にします。`?`・`=`・`&` は半角です。
- それでも通知に文面が出ないときは、通知はあきらめて、「通知を表示」のアクションを消すか、内容を「記録しました」のような固定の文にしてください。ページ（手順7）だけで確認する使い方になります。

### 体重の値がおかしい（150前後の大きな値になる）

- 単位がポンド（lb）で送られています。手順5の(3b)で、値の単位を **kg** にしてください。
- 直したあとにもう一度送ると、同じ時刻の測定は正しい値で上書きされます。それでも残った行は、「体重ログ」で手で消してください。

### オートメーションが動かない

- 「閉じたとき」「すぐに実行」はiOS 17以降の機能です。iOSを更新してください。
- それでも動かないときは、オートメーションを「**開いたとき**」に変えてください。手順5の「待機」があるので、開いてから5秒後に送られます。この場合は、測ったあとにオムロン コネクトを開いて、値が入るのを待ってから閉じてください。
- 通知だけ出ない場合は、上の「通知が出ない」を見てください。

### 今日の体重が記録されない（前の日までは入っている）

- アプリを閉じた時点で、オムロン コネクトがまだヘルスケアに書き込んでいなかった可能性があります。ショートカットの「待機」を5秒から10〜15秒に延ばしてください。
- 毎回14日分を送るので、今日の分は次に送ったとき（明日の朝など）に自動で埋まります。急ぐときは、ショートカットを手で実行してください。
- ヘルスケアの「体重」に今日の値が入っているかも確かめてください（手順4）。

### ページに「表示できませんでした」と出る

- その下の文章に、何が足りないかが書いてあります（上の表の「意味」と「直し方」が当てはまります）。
- スプレッドシートの「設定」または「体重ログ」を直してから、ページを開き直してください。

### ページに「まだ記録がありません」と出る

- 「体重ログ」に行がありません。手順5のショートカットを一度手で実行してください。
- ページと受け取り口の `SHEET_ID` が同じスプレッドシートを指しているか確かめてください。

### ページを開くとログインを求められる、「アクセス権がありません」と出る

- ページのApps Scriptを作ったのと同じGoogleアカウントでログインしてください。Safariに複数のGoogleアカウントでログインしている場合は、アカウントを切り替えます。
- 「プライベートブラウズ」では毎回ログインが必要です。通常のタブで開いてください。

### 「設定」を変えたのにページが変わらない

- ページは開くたびに読み直します。一度閉じてから開き直してください（アプリのように開いている場合は、上から下に引っ張って更新するか、閉じて開き直す）。

### コードを直したのに動きが変わらない

- Apps Scriptは、保存しただけでは公開中のページに反映されません。「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」をしてください（2.4の補足）。
